# Modular AI Pipeline Orchestration Tool

A full-stack, interactive node-based workflow builder that allows users to construct AI pipelines with real-time graph validation.

## 🚀 Live Demo
[**Click here to view the Live Project**](YAHAN_APNA_VERCEL_URL_PASTE_KAREIN)

## ✨ Key Features
- **Interactive Drag-and-Drop UI:** Built with React Flow for seamless pipeline construction.
- **Dynamic Variable Parsing:** Automatically detects `{{variable}}` syntax in text nodes to create dynamic input handles.
- **DAG Validation:** Backend logic (FastAPI + NetworkX) ensures the pipeline is a Directed Acyclic Graph, preventing infinite loops.
- **9+ Custom Nodes:** Includes LLM, Input, Output, Text, Translator, API, Logic, Database, and Note nodes.

## 🛠️ Tech Stack
- **Frontend:** React.js, React Flow, Zustand (State Management).
- **Backend:** Python, FastAPI, NetworkX (Graph Algorithms).
- **Deployment:** Vercel (Frontend & Serverless Backend).
